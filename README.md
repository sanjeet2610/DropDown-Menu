# @sanjeetkr/dropdown

A lightweight, reusable, and dependency-free dropdown menu for vanilla JavaScript.

![License](https://img.shields.io/npm/l/@sanjeetkr/dropdown)
![Version](https://img.shields.io/npm/v/@sanjeetkr/dropdown)

## Features

- ⚡ **Zero Dependencies:** Pure Vanilla JS.
- 🔄 **Reusable:** Supports multiple dropdowns on a single page.
- 🛡️ **Safe:** Scoped logic prevents conflicts with other elements.
- 🎨 **Flexible:** You control the HTML and CSS.

## Installation

Install the package via npm:

```bash
npm install @sanjeetkr/dropdown
```
